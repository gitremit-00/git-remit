# Demo Script

1. Open the web app and register as a sender.
2. Complete the facial recognition and government ID verification demo steps.
3. Connect a local MetaMask wallet.
4. Create an ETH pledge for a merchant with a partial deposit.
5. Switch to the merchant dashboard and show the pledge with locked funds.
6. Return as the sender and complete the remaining deposit.
7. Switch back to the merchant dashboard and release the payment.
8. Repeat the same flow with mock USDC or mock USDT using token approval first.
9. Show pledge history, status tracking, and reputation score changes.
